# Portfolio

W tym repozytorium znajdują się dwa projekty:

1. **System Baz Danych – Kursy i Szkolenia**  
   Projekt bazodanowy zaprojektowany dla firmy oferującej kursy, szkolenia i studia w modelu hybrydowym. System obsługuje zapisy, płatności oraz generowanie raportów.

2. **Spotify Top Songs – Wizualizacja Danych**  
   Analiza danych najpopularniejszych piosenek ze Spotify przy użyciu Tableau. Projekt zawiera interaktywny dashboard prezentujący statystyki muzyczne.

## Technologie
- **System Baz Danych**: SQL, SSMS
- **Spotify Top Songs**: Tableau, Excel
