# Spotify Top Songs – Wizualizacja danych

Projekt polega na analizie i wizualizacji danych dotyczących najpopularniejszych piosenek ze Spotify. Wizualizacja została przygotowana w Tableau i prezentuje kluczowe statystyki dotyczące trendów muzycznych.

## Zawartość
- Dashboard Tableau z interaktywną wizualizacją
- Zrzut ekranu z gotowego dashboardu
- Plik z danymi źródłowymi użytymi do analizy

## Co zawiera dashboard:
- Najpopularniejsze tonacje i tryby
- Rozkład popularności piosenek w czasie
- Średnie wartości cech muzycznych (danceability, energy, valence itp.)
- Porównanie ilości występujących artystów
