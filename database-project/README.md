# Baza Danych – Projekt

Projekt systemu bazodanowego dla firmy oferującej kursy, szkolenia oraz studia w modelu hybrydowym (webinary, kursy krótkoterminowe, studia długoterminowe). System uwzględnia specyfikę różnych typów usług oraz procesów płatności.

## Zakres projektu
System obejmuje:
- projekt bazy danych (schemat tabel i relacji),
- definicje tabel z warunkami integralności,
- widoki ułatwiające dostęp do danych i generowanie raportów,
- procedury składowane i funkcje wspomagające obsługę systemu.

## Główne funkcjonalności
- Obsługa zapisów na webinary, kursy i studia,
- Zarządzanie harmonogramem zajęć (stacjonarnych, on-line i hybrydowych),
- Kontrola płatności i dostępów do wydarzeń,
- Śledzenie obecności uczestników i zaliczania modułów,
- Raportowanie m.in. przychodów, frekwencji i bilokacji.
